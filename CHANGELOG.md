# Changelog

Notable changes to Lens are recorded here.

## [Unreleased]

### Added

- Browser control: tabs, windows, frames, page inspection, semantic locators, and ref-based actions.
- Network capture, response bodies, request export, and performance metrics.
- Emulation for network, CPU, geolocation, devices, viewports, and touch.
- Publishing from the same CLI.
- Verification tooling: visual diff, DOM diff, and screenshot bisect.
- Headless mode, request interception through `serve`, named flows, and a socket API.
- A supported client for the host socket (`@lens-cli/lens/client`).
